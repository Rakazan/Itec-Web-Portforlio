Programs I used

The programs I used to make my projects are featured below.

Magicavoxel

MagicaVoxel is a free 3D modeling program used to create voxel art—3D rendered images and models made from tiny cubes.

Piskel

Piskel is a free online program for creating pixel art and animated sprites.

Adobe Illustrator

Adobe Illustrator is a graphic design program used to create scalable vector artwork, such as logos, icons, and illustrations.

Adobe Photoshop

Adobe Photoshop is an image-editing program used to modify photos and create digital artwork.

Visual Studio Code

Visual Studio Code is a lightweight code editor used to write, test, and debug computer programs.

Pivot Animator v5

Pivot Animator v5 is an animation program used to create stick-figure animations frame by frame.

CapCut

CapCut is a video-editing program used to create and enhance videos with effects, music, text, and transitions.

Unity

Unity is a game development program used to create 2D and 3D games and interactive games.
